# Verified Delivery

Completion is a supported state, not an agent assertion. Codex Small Loop returns
a result only when the delivered files or behavior, the four Review outcomes,
the final severity of every Signal, and the relevant automated and
real-environment checks agree with the approved acceptance bar.

Review responsibilities are intentionally complementary. Baseline Verification
runs the broad reusable mechanical checks once; Trust Review checks safety and
defensibility; Technical Excellence Review checks simplicity and long-term
maintainability; and Customer Value Review checks the agreed outcome and user
value. Primary integrates those independent results, finalizes each Signal's
severity, and accepts the exact candidate state after required corrections.

Evidence is proportional to the change. Documentation work needs graph, link,
and contract proof; runtime work may also need process, lifecycle, and installed
plugin checks. Limits remain visible rather than being silently converted into
confidence.
